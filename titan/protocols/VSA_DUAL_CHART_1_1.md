# TITAN VSA-2 1.1 — Mandatory Two-Asset Candlestick and Structural Report

**Adopted request:** 28 October 2026  
**Status:** ADDITIVE RESEARCH / PRESENTATION PROTOCOL, NOT DEPLOYED. No autonomous chart scheduler, authenticated ten-agent run, trade execution, or backtest is implied.

## Supersession and invariant hierarchy

This protocol **supersedes the chart-COUNT rule only** in the earlier [SDRC-MTF 1.0](SDRC_MTF_1_0.md) research/reporting overlay: produce **TWO** asset charts for the top TWO ranked securities instead of only one. All preceding underlying requirements remain: authentic externally sourced completed OHLC; multi-timeframe / forward Ichimoku and demand/supply validation; complete independent ten-agent signed quorum; untouched six TITAN phases and strategy parameters; event blackout, structural stop/verified opposing zone, minimum **net TP1 reward/risk of 2.5:1**, portfolio controls, and only one active trade/no concurrent pending orders. Two **research charts never mean two live orders**. The separate proposed cross-asset two-position exception remains inactive pending ratification.

The user wants **both charts each time a completed ranked TITAN opportunity report includes at least two assets**. This rule is mandatory for presentation, not an excuse to fabricate candles or unauthorized order levels. If the required authentic data for either instrument are missing, generate a visibly labelled **DATA UNAVAILABLE / NO MARKET CHART** panel for that rank, with missing OHLC/zone/price fields null and **NO TRADE**; never draw synthetic candles as observed prices. A genuinely executable setup requires complete existing risk gates regardless of its rank.

## Order of operations — independent rankings, then both visuals

1. Freeze an as-of timestamp; ingest externally sourced, permitted, **non-broker-originated** market OHLC history, metadata (exchange/venue/symbol/contract/roll, exact interval, timezone), last complete candle and source freshness. Rank both directions, with independent signed evidence and all frozen strategy checks; if no computed WCS/candidate score, label **UNSCORED**, never fabricate an exact score or winning probability.
2. Select the top TWO **research-ranked** assets (including unapproved/watch candidates if that is what the table contains). Never silently replace rank #1 or #2 with a more convenient instrument because data are missing. An asset-class/same-class correlation rejection is retained in rank and must not become a second open position.
3. For each asset in exact rank order, compute chart with Python code and Matplotlib candlesticks; **prefer mplfinance** if installed, and use `matplotlib.patches.Rectangle` for zone rectangles. A faithful native matplotlib candlestick fallback is acceptable when mplfinance dependency is absent, with the renderer reported. Write the generated PNG to a real verified output path and show the actual graphic; do not respond with *only* source code when execution works.
4. Plot **real completed OHLC candlesticks** (default the latest 120 bars if available; shorter factual series with count disclosed). Identify candidate **green demand** rectangles and **red supply** rectangles, with documented candle-origin dates and proximal/distal boundaries. Mark entry as **blue**, stop as **red**, TP1 (and TP2 if available) as **green**, with exact price figures. Keep labels distinct and legible. Where targets or stops are only derived conditional research examples from actual observed swing highs/lows, make that unambiguously visible. Such inferred levels are *not* verified live entries and may fail risk checks.
5. **No invented values:** If authentic prices or structurally justified zone boundaries are not available, set numeric fields to JSON **null**, show the missing-evidence message in the chart area and report **NOT VALIDATED — NO TRADE**. Do not invent candle OHLC, volume, supply/demand boundaries, chart levels, broker spreads, WCS votes or an R:R.
6. Verify initial level ordering: LONG `stop < entry < nearest TP1`; SHORT `nearest TP1 < entry < stop`. Reconcile with first genuine opposing structure; calculate **gross RR** if defensible historical levels exist, but only calculate **net RR** after authentic current broker/venue bid-ask and documented commission/slippage/financing. If gross < 2.5, net cannot pass a reasonable non-negative cost assumption. Even if gross >= 2.5, do not claim net eligible without quote/cost evidence. Broken strategy, event and signed agent checks always force NO TRADE.
7. At least visually inspect both saved PNGs for readability, timestamped axes, correct candle direction, clear colour contrast, correct source note, visible zone heights and no misleading cropped prices. The source must allow the rendered chart to be reproduced with deterministic calculations. If a report cites earlier-crawled data that have become stale, say exactly which completed session was included.
8. Under each image include (a) front-end JSON object with `asset`, `chart_elements {supply_zones[],demand_zones[],entry_price,stop_loss,take_profit}`, (b) 3–4 sentences explaining targeted/defended zone, mathematical entry/SL/TP rationale, precise invalidation and confirmation state, (c) score if genuinely available, else `Unverified`, and (d) citation to dated original OHLC sources. Return **both chart sections** with no extraneous market hype.
9. Prefer exact requested text sequence: `### ASSET #1: [symbol] (WCS Score: [score/unverified])` -> image -> structural JSON -> short explanation, then same `### ASSET #2`. Never allow the strict report format to suppress a mandatory NO_TRADE / missing-data notice.

## Chart and model distinctions

- An observed chart-based swing area is only a **candidate** supply/demand zone; do not call it a confirmed unmitigated *institutional* block without evidence or independent zone-validation rule. Chart colours do not certify order flow.
- Current-price annotations are subject to reported price as-of; incomplete day/hour bars are not completed historical candlesticks. Display source time zone, nontrading gaps, symbol, price units, tick, instrument type.
- For a 3–10-session horizon, the default strategic charts are W1/D1 with H4 entry chart; if H4 cannot be sourced, a D1 exploratory candlestick chart can be supplied but **NOT an executable H4 analysis**. Do not reconstruct fake H4 candles from daily data.
- The 4-scorer CCEE WCS, 10-signed-specialist votes and CATPR composite scores are distinct metrics. A published research priority order does not establish numerical WCS.
- A cash index such as NDX is **not itself an executable broker instrument**. Its diagram must not be labelled an available fill without a specific index future/ETF/CFD and executable bid/ask validation.
- Two research visualisations are a **format commitment**; they do not change the mandate to choose at most one approved opportunity for an actual test trade, nor activate the proposed cross-asset portfolio exception.

## Reproducibility and checks

Before integration validate: top-two stable order; zero or one ranked asset; source mislabels; 20–120+ real candles; calendar/timezone gaps; correct O/H/L/C body/wicks; patch zone origin/extent; margin for blue/red/green labels; exact price tick rounding; no lookahead; stale/incomplete candle rejection; null JSON no numeric defaults; same-class correlation refusal; no implicit trade approval; missing H4 ≠ inferred H4; gross vs net R:R correctly differentiated; changed historical data feed not silently substituted.

A **local example** can use archived 27 October 2026 copper futures HGZ26 daily candles from reported public sources and Nasdaq-100 cash index NDX daily candles, but should explicitly remain a **D1 research demonstration**, not a live market scan, contemporaneous quote or validated institutional order-block algorithm.
